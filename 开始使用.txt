ChronoLens · 时序异常检测与解释系统

一、立即运行
双击本目录 start.bat，等待浏览器自动打开 http://127.0.0.1:8767 。
窗口需保持开启，Ctrl+C 停止该次启动的服务。
若同版本服务已经在运行，start.bat 直接打开已有服务，不重复创建进程。
仓库包含已构建的 frontend/dist；首次运行会创建本机 .venv 并安装 Python 依赖。
本次后端协议为2.0.0；升级前先在旧服务窗口按Ctrl+C停止，再运行start.bat，避免复用旧版API。

二、独立训练与模型复用流程
1. 导入历史 CSV，或点击“生成演示”生成 2400 点合成服务器数据。
2. 进入模型训练与管理页面，选择数据集、模型名称和算法。
3. 合成演示可设置：拟合起点 0、拟合终点 672、校准终点 840；阈值分位数 99%。区间为零基、左闭右开。
4. 点击训练，等待真实任务完成，再发布生成的模型版本。
5. 返回分析工作台，上传或选择新数据，选择兼容的已发布模型，点击“开始异常检测”。检测不会重新训练。
6. 查看分数、事件、变量解释；保存人工复核和备注，导出 CSV / HTML。
7. 演示可对同一合成数据检测，但真实效果评估必须使用独立测试数据。Ridge 历史不足会显示“预热/不可评分”，不当作正常。
8. 模型文件、填充值、标准化参数和阈值均已保存；停止并重启后仍可选用。列顺序可以变化，缺少或多出特征会被拒绝。

三、环境与首次安装
推荐 Python 3.10、3.11 或 3.12；本机使用 Python 3.10 验证。
首次在新机器运行需联网安装 requirements.txt 中的依赖。
预构建界面存在时，正常运行不需要 Node.js，不需要显卡、大模型 API 或账号。
只在重新构建前端时需要 Node.js 24：在 frontend 中执行 npm ci 与 npm run build。
迁移到其他机器时不要复制使用旧 .venv；虚拟环境不具备跨机器可移植性。

四、常用入口
完整使用说明：双击 使用说明.html
API 交互文档：http://127.0.0.1:8767/docs（Swagger 界面资源需要网络）
API 原始规范：http://127.0.0.1:8767/openapi.json
其他端口：start.bat --port 8768
不自动打开浏览器：start.bat --no-browser
源数据格式与注入异常位置：examples/data_dictionary.json
运行记录与上传数据默认保存于 backend/data；备份时先停止服务，再复制整个目录。

五、公开数据集：SMD 单台服务器
推荐 machine-1-1：同一台服务器的训练、测试和测试标签，38 个匿名指标。不要混合不同机器训练。
官方来源：https://github.com/NetManAIOps/OmniAnomaly/tree/master/ServerMachineDataset
在项目目录执行：
.venv\Scripts\python.exe scripts\prepare_smd.py --machine machine-1-1 --download
生成 datasets\SMD\prepared\machine-1-1_train.csv 和 machine-1-1_test.csv。
先导入 train.csv 训练：拟合起点 0，拟合终点取训练行数的 80%，校准终点取全部训练行数；以脚本输出的建议值为准。
发布模型后导入 test.csv，选择同一模型检测。测试文件包含 is_anomaly 标签，标签仅用于评估，不参与训练或阈值选择。
原始 SMD 没有时间戳，平台使用样本序号；metric_01 等只是稳定列标识，不是假定的 CPU/温度名称。
网络不能直连 GitHub 时，手动下载官方 train/test/test_label 文件夹，然后执行：
.venv\Scripts\python.exe scripts\prepare_smd.py --source-dir "下载后的ServerMachineDataset目录"

六、独立脚本训练
.venv\Scripts\python.exe scripts\train_model.py datasets\SMD\prepared\machine-1-1_train.csv --name SMD-machine-1-1-PCA --algorithm pca --publish
脚本与平台使用同一训练核心和默认数据目录。训练成功后刷新模型管理即可选择，不需要导入任意外部模型文件。

七、已执行验证
35 项 Python 行为回归、4 项 Node CSV 行为检查、严格 TypeScript 和生产构建通过。
真实服务：三算法训练/保存/发布/独立推理、进程重启后分数和阈值一致、列重排、整列缺失值填充及短批次检测。
时序：整批与分批预测一致，单点批次续接、不同流隔离、重叠拒绝、时间断层重新预热，失败任务不推进状态。
真实浏览器：页面训练与发布、新数据模型选择、图表缩放、解释、复核保存、CSV/HTML 下载与刷新历史通过。
1512px 桌面及390px移动端无横向溢出、无浏览器运行时错误。旧版现场拟合历史仍可查询与导出，不伪造模型ID。
记录与截图位于 artifacts/model-lifecycle；流程成功不代表真实业务准确率。变量贡献不是因果根因。

八、其他功能与边界
- 数据诊断：变量分布、缺失比例、采样质量和相关矩阵。
- 检测任务对比：同一数据集最多比较三次已完成任务，展示实际模型版本和可评分样本；不同算法分数不可直接比较。
- 事件探索与复核：关键词/严重度/状态筛选、分页、排序、批量复核及前后事件跳转。批量只改结论，备注草稿需单独保存。
- 导入：CSV拖放、UTF-8/GB18030表头预览与时间/标签列映射；支持1–100000行、2–64个数值变量，最大25MiB。
- 未开放任意 joblib/pickle 模型上传；仅加载平台或同一训练脚本生成的可信模型。
- 当前为本地批量分析，不包含公网鉴权、自动告警、自动漂移重训练或持续实时采集。
