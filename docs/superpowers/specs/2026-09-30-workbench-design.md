# ChronoLens 前后端优化方案

## 目标
在现有 React / FastAPI 系统上进行整体优化，保留真实三算法检测、历史校准、事件解释、CSV 导入和离线报告。

## 推荐方案：专业分析工作台
- 浅色分析主区、深色导航、青绿主色与语义化异常色；正文 14px 左右，提升灰字对比，统一按钮、卡片、表格和状态。
- 已完成分析时先展示结果、趋势图和复核进度；数据预览与检测配置放入可收起的设置区，首次检测时默认展开。
- 工作台、数据管理、数据诊断、模型对比、检测历史之间采用统一导航；移动端保持完整功能并支持表格局部滚动。
- 新增数据诊断：缺失率、变量统计、采样间隔和相关矩阵，全部基于真实导入数据计算。
- 新增模型对比：在同一数据集下比较已完成任务的异常比例、事件数、运行耗时和标签指标；标注配置差异，不跨算法比较原始分数。
- 新增事件搜索、严重程度与复核状态筛选、排序、选择与批量复核；保留逐事件解释和备注。
- 后端新增诊断与运行洞察接口、原子批量复核；CSV 解析移入工作线程；数组缓存设容量和文件更新失效规则。

## 其他选择
1. 仅优化视觉：交付快，但不能解决功能和后端诉求。
2. 全量重写：工作量与回归风险较高，现有算法和持久化已有可用基础，暂不建议。

## 数据与错误处理
现有 backend/data 原样保留；新功能兼容已有 SQLite 记录；空数据、无标签、失败任务、缺失统计、请求中状态均有明确反馈。批量复核任一事件不存在时不更新任何事件。

## 验证
后端真实统计与 API 行为测试、原有回归测试、TypeScript 检查和生产构建；浏览器验证导入、检测、图表联动、诊断、对比、单个与批量复核、导出和刷新恢复；检查桌面与移动端布局与运行时错误。
